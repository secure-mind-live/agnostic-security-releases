# AgnosticSecurity Releases

Pre-built AgnosticSecurity extensions for VS Code, Chrome, and Cursor. No build toolchain required — download and install.

## Latest Release

Download from the [Releases page](https://github.com/secure-mind-live/agnostic-security-releases/releases).

### Available Packages

| Package | Description |
|---------|------------|
| `agnostic-security-X.Y.Z.vsix` | VS Code extension |
| `agnostic-security-chrome-X.Y.Z.zip` | Chrome extension |
| `agnostic-security-cursor-X.Y.Z.vsix` | Cursor extension |

### Install

**VS Code:**
```bash
code --install-extension agnostic-security-X.Y.Z.vsix
```

**Chrome:**
1. Unzip `agnostic-security-chrome-X.Y.Z.zip`
2. Go to `chrome://extensions` → Enable Developer mode → Load unpacked

**Cursor:**
```bash
cursor --install-extension agnostic-security-cursor-X.Y.Z.vsix
```
